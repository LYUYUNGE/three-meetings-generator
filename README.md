# 公司三会文件生成系统（本地离线版）

双击 `start.bat` 后，在浏览器打开 `http://127.0.0.1:8765`。

- 支持董事会、监事会和股东会；董事会/监事会生成 8 份 Word，股东会生成 9 份 Word。
- 文件逐份生成和下载，不自动打包 ZIP。
- 生成记录保存在 `data/records.json`，可从网页调取修改。
- 新建下一套文件前，系统要求确认上一套是“通知定稿版”或“签署定稿版”，并复制到 `archive` 对应目录。
- 服务只绑定 `127.0.0.1`，页面不引用 CDN、统计、登录或云接口。
- 参考文件名称和网址随表单记录保存在本机；网址不会联网抓取。议案初稿由本地规则生成，正式使用前应人工复核事实、日期、权限和表述。

模板分别位于 `templates/board` 与 `templates/shareholder`。监事会当前沿用董事会版式并自动切换机构和职务称谓。
